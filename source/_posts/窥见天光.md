总在担心我的 Binance、Pump.fun、Phantom、X，都是基于我的谷歌账号，基于一个我也不太了解的 VPN。哪一天谷歌没了，那我的币咋办？

后来幡然醒悟，币是去中心化的，只要记得密钥就没有问题。😄

这是去中心化对于一个肉身在墙内，社会主义人民的一个曲线福利吗😂。

今天第一次交易 meme，确实很刺激，一个小时就亏掉了我一个星期 A 股亏的钱。

复盘我交易的思路，每一秒都有一个新的 meme 币出现，一个 meme 币的黄金期只有短暂的半分钟。没有背书的 meme 币，照我这样交易完全拼运气，完全送学费。

我喜欢 meme 币，因为它对于我这样没有多少本金的人，是几乎唯一翻盘的机会。

但是 meme 和 A 股完全不一样，它完全必须要有 agent 的帮助，必须要有 agent 去帮你追踪聪明钱包，必须要有 agent 去帮按照客观、按照百分比快速买入卖出。

Pump.fun 还尚未主流，FOMO 也未主流。我庆幸我终于缩短了与先进交易的距离🥹，虽然现在对 FOMO 一无所知，但是至少窥见一点天光。

未来几天估计也不会交易了，专心去组合 agent，训练并给出提示词，优化给组合 agent 的交易策略。如果交易策略是垃圾的话，那我只能产出制造垃圾特别快的超级撒钱 agent😄。

不交易的一个原因还有，市面上先进 agent Plus 几乎 200～300/月，一个 agent 肯定不够😄。

不知道我的电脑撑多久，意淫一下赚到第一桶金的话，估计也是买一个性能强的电脑了。

FOMO，我来了。
